# Dragon Block: Tenkaichi

**Authors:** Sh4d0wJ0J0 and Claude

> 🤖 **This mod was created entirely with Claude** (Claude Opus 5.5, an AI model by Anthropic) using
> [Claude Code](https://claude.com/claude-code): the code, multi-loader architecture, script-generated
> assets (textures, sounds, translations), tests and documentation were written by Claude at the
> request of the repository owner.

A Dragon Ball-inspired RPG mod for **Minecraft Java 26.3**, targeting both **Fabric** and **NeoForge**
from a single codebase. Unofficial fan project, not affiliated with Bird Studio, Shueisha, Toei
Animation or Bandai Namco. All assets (textures, models, sounds) are original and generated by the
scripts in `tools/`.

## Status

Version **0.1.0 — vertical slice**: character creation with all 10 playable races (Saiyan, Half-Saiyan,
Human, Namekian, Frieza Race, Majin, Android, Bio-Android, Kaioshin, Demon Realm Race), each with its own
server-side passives, 3D features and HD procedural skin, 12 stats, Battle Power,
melee combat with combos/guards/dodges, lock-on, flight, Ki charging, 3D aura, Ki Blast, Kamehameha,
Beam Clash, Super Saiyan, a trainer Master, a Saiyan Raider with AI, a fully custom UI (HUD with portrait,
gauges and technique icons, themed menus), custom particles, first-person combat arms, multiplayer sync,
saving and configuration. Details in `docs/FEATURES.md`, verification status in `docs/PROGRESS.md` and
`docs/TESTING.md`, limitations in `docs/KNOWN_ISSUES.md` (project docs are currently in Italian).

## Requirements

- JDK 25 (the script automatically uses the Minecraft launcher's Java 25 runtime if present)
- Fabric: Fabric Loader ≥ 0.19.5 and Fabric API 0.162.0+26.3
- NeoForge: 26.3.0.71-beta or later

## Build

```bash
./scripts/gw.sh build
```

On Windows PowerShell: `scripts\gw.ps1 build`. The script sets up Java 25 and the Windows trust store
(needed when an antivirus intercepts HTTPS). The two final JARs are copied to `build/release/`:

- `dragon-block-tenkaichi-0.1.0-26.3-fabric.jar`
- `dragon-block-tenkaichi-0.1.0-26.3-neoforge.jar`

## Testing

```bash
./scripts/gw.sh :common:test
./scripts/gw.sh :fabric:runServer -PdbtSmoke
./scripts/gw.sh :neoforge:runServer -PdbtSmoke
./scripts/gw.sh :fabric:runClient -PdbtSmoke
```

Smoke tests are only enabled with `-PdbtSmoke` (system properties `dbtenkaichi.smokeTest` /
`dbtenkaichi.clientSmoke`) and shut down on their own. The client test needs the world
`runs/client/saves/dbt_test` (see `docs/TESTING.md`) and saves screenshots to `runs/client/screenshots`.

## Controls (defaults, all rebindable)

| Key | Action |
|---|---|
| R (hold) | Charge Ki — during a Beam Clash: pulse on the beat |
| G | Toggle flight (Space up, Shift down, Sprint = supersonic) |
| H | Combat stance (left click: combo / hold = heavy attack, right click: guard) |
| Left Alt | Directional dodge / vanish behind the locked target |
| Z | Dash (towards the locked target) |
| J / K | Lock on / next target |
| V / B | Transform / power down |
| X, C, N, M | Technique slots 1–4 (hold to charge beams) |
| U | Character menu |
